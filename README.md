# Посмотри в окно

Проектная работа по вёрстке. Учебный проект

## Функциональность

- Поиск видео по городу и времени суток
- Просмотр видео в плеере
- Смена видео по клику
- Адаптивная вёрстка

## Стек

- HTML5 (готовый)
- CSS3
  - Flexbox
  - Grid
  - Псевдоэлементы
  - Кастомный скроллбар
- JavaScript (готовый)

## Особенности вёрстки

- Только CSS, HTML не менялся
- Кастомные чекбоксы через `::after`
- Кастомный скроллбар (4px) (задавался)
